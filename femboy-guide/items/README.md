# 社区用品推荐

这里收录社区贡献者亲自使用过的情趣用品、男性用品及女性化表达相关工具。推荐帮助用户建立候选清单，不代表项目、生如夏花知识库或医学机构背书，也不保证商品适合每个人。

> 仓库包含成人用品内容，仅限年满 18 周岁的成年人阅读和使用。未成年人勿看勿用，后果自负。

## 投稿用品

复制 [`_template.md`](_template.md) 到最匹配的分类目录，文件名使用商品名或型号的简短英文形式，例如：

```text
brand-product-model.md
```

模板只要求：商品名、分类、商品链接、是否成人限定、是否亲自使用、商业关系披露，以及正文中的用法和推荐理由。其他部分可按需要删改。

简单约束：

1. 推荐者必须亲自使用过该商品；不收录只看广告、转述他人或由 AI 生成的推荐。
2. 使用商品官方页或正规零售页面的完整 HTTPS 链接；不接受短链、邀请链接、返利或联盟追踪链接。
3. 赠品、赞助、联盟关系、卖家或制造商身份必须在 `commercial_relationship` 中披露，即使正文评价是负面的。
4. 用自己的话写实际用法、推荐理由、缺点和不适用情况；不复制商家宣传，不承诺高潮、身体改变、治疗疾病或其他固定效果。
5. 不收录处方药、激素、注射剂、来源不明的医疗器械、麻醉型性用品、无可靠防滑底座的肛用玩具、家居插入物或其他明显危险商品。
6. 涉及身体接触的用品应说明材质、清洁、润滑兼容性、尺寸或停止信号中真正相关的部分；商品说明与医学安全冲突时，以更安全的做法为准。
7. 链接、规格、配方和在售情况可能变化。投稿者填写 `last_checked`，Agent 引用前仍应实时核对商品页面。

维护者可以拒绝广告化、未披露利益关系、无法核对链接、过度承诺或存在明显安全风险的推荐。
