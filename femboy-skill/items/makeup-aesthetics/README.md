# 化妆和医美

收录剃须、脱毛、护肤、化妆、胡青校色及医美前后护理相关用品。

不收录医美机构排名、医疗项目软广、处方药、自购激素、注射剂、家用注射或把普通化妆品描述成医疗治疗的推荐。涉及刺激性成分时说明局部测试和停止信号；医美方案与术后处理应由合格医疗专业人士评估。
## 激光脱毛
美团搜索“男士脱毛”，“激光脱毛”
### 价格参考
单部位（如上唇）脱毛正常价位约为 单次 60 -120元，低于这个价格则大概率脱毛效果差/无效，高于这个价格则属于过高溢价。
因此唇周脱毛单次正常价格约为 120-240元（上唇和下巴）。
