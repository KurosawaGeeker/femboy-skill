# 社区真实案例库

这里收录由成年贡献者自愿提交、完成个人信息脱敏的第一手真实经历。案例用于帮助使用者理解“别人遇到过什么、尝试过什么、结果如何”，不是医学证据、处方、效果保证或标准答案。

> 仅限年满 18 周岁的成年人阅读和投稿。未成年人勿看勿用，后果自负。

## 如何检索

先按主题目录缩小范围，再用经验阶段和结果筛选：

| 主题目录 | 收录范围 |
|---|---|
| [`voice/`](voice/README.md) | 伪音、嗓音女性化、练习瓶颈与声音保护 |
| [`presentation/`](presentation/README.md) | 护肤、妆容、胡青、穿搭、身材与日常表达 |
| [`sexual-wellness/`](sexual-wellness/README.md) | 成年人的前列腺、后庭、乳首、非射精高潮、潮吹、催眠音声及相关身体探索 |
| [`healthcare/`](healthcare/README.md) | 就医沟通、检查、用药观察与不良反应处理经历 |

案例元数据使用以下经验标签：

- `experience_level`：`first-attempt`、`beginner`、`repeated`、`long-term`；
- `outcome`：`helpful`、`mixed`、`ineffective`、`stopped`、`adverse-event`。

[`taxonomy.json`](taxonomy.json) 是类目与经验标签的机器可读定义；新增类目或标签时应先修改它，再同步目录和本文说明。

全部已收录案例见 [`INDEX.md`](INDEX.md)。案例较多时可在本目录中搜索字段或关键词，例如：

```bash
rg -l --glob '*.md' --glob '!README.md' --glob '!INDEX.md' --glob '!_template.md' \
  'category: voice|experience_level: beginner|outcome: mixed' cases
```

检索结果应优先匹配用户的主题、经验阶段、目标与主要限制。不要只挑“成功案例”；无效、停止和不良反应案例同样重要。

## 投稿真实案例

复制 [`_template.md`](_template.md) 到对应主题目录，文件名使用不含个人信息的英文短名，例如：

```text
2026-08-resonance-practice-mixed-result.md
```

模板是宽松指引：基础元数据与带“必填”的正文需要保留，其他部分可按实际经历删改。一个案例可以提及相关主题，但应放在最主要的一个目录，并在 `related_categories` 中补充其他类目。

投稿必须满足：

1. 是投稿者本人真实经历，不能转载、代投、拼接或由 AI 虚构；可以使用 AI 帮助整理，但必须逐项核实。
2. 投稿者在经历发生时及投稿时均已年满 18 周岁；案例不能包含未成年人的露骨经历。
3. 删除姓名、账号、联系方式、精确年龄、精确日期、精确住址、单位/学校、订单号、病历号、可定位机构、照片、录音和其他可交叉识别信息。
4. 伴侣、医生或第三人的信息也必须脱敏；没有对方明确许可时，不应描述可识别的私密细节。
5. 如实记录无效、失败、停止与不良反应，不夸大因果，不承诺他人可复现。
6. 医疗与用药案例不得提供个体处方、具体剂量、绕过处方的购买渠道或鼓励自行停药；重点记录就医、监测、症状和如何寻求专业帮助。
7. 投稿即表示同意按本仓库的 CC BY-SA 4.0 许可公开和再分发脱敏后的内容。

维护者可能为安全、清晰度和进一步脱敏而提出修改，也可能拒绝仍有识别风险、无法确认真实性边界或鼓励危险行为的案例。
