# 社区消费指南

这里收录社区贡献者亲自购买、使用或到店体验过的商品、服务和店面，覆盖情趣用品、化妆和医美、女装配饰等主题。记录帮助用户建立消费候选清单，不代表项目、生如夏花知识库或医学机构背书，也不保证适合每个人。

> 仓库包含成人用品内容，仅限年满 18 周岁的成年人阅读和使用。未成年人勿看勿用，后果自负。

## 投稿消费记录

复制 [`_template.md`](_template.md) 到最匹配的分类目录，文件名使用商品、服务或店面的简短英文名称，例如：

```text
brand-product-or-store.md
```

模板只要求：名称、类型、分类、链接、是否成人限定、是否亲自体验、商业关系披露，以及正文中的消费方式和推荐理由。地区、价格、自查标准等内容可以按商品、服务或店面的实际情况增删。

简单约束：

1. 推荐者必须亲自购买、使用或到店体验过；不收录只看广告、转述他人或由 AI 生成的推荐。
2. 使用商品官方页、正规零售页面、服务页面或店面页面的完整 HTTPS 链接；不接受短链、邀请链接、返利或联盟追踪链接。
3. 赠品、赞助、联盟关系、卖家、制造商、服务提供方或店面从业关系必须在 `commercial_relationship` 中披露，即使正文评价是负面的。
4. 用自己的话写实际消费方式、推荐理由、缺点和不适用情况；不复制商家宣传，不承诺高潮、身体改变、治疗疾病或其他固定效果。
5. 不收录处方药、激素、注射剂、来源不明的医疗器械、无资质医美服务、麻醉型性用品、无可靠防滑底座的肛用玩具、家居插入物或其他明显危险消费项目。
6. 涉及身体接触的商品或服务应说明材质、清洁、润滑兼容性、资质、风险或停止信号中真正相关的部分；商业说明与医学安全冲突时，以更安全的做法为准。
7. 链接、规格、价格、地址、服务人员和营业状态可能变化。投稿者填写 `last_checked`，Agent 引用前仍应实时核对页面。

维护者可以拒绝广告化、未披露利益关系、无法核对链接、过度承诺或存在明显安全风险的消费记录。
